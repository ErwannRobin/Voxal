📹 Video

Blur what is behind you, or replace it. Applies to your camera only, and everything is computed on this device — no frame is ever sent anywhere to do it.

How far the blur reaches, as a share of the picture — so it looks the same whatever your camera's resolution. Applies while the background is set to Blur, and reaches the main window immediately, even mid-call.

How hard the cut-out between you and your background is. Softer hides the odd stray pixel and suits hair, glasses and a cluttered room; sharper keeps a crisp outline and suits a plain wall. Applies to the blur and to background images alike, reaching the main window immediately, even mid-call.

How often you are picked out of the picture again. High follows fast movement more closely and costs more battery; Battery does the opposite. A device that cannot keep up is stepped down on its own whatever you choose here.

In a dim or backlit room, brightens the copy of the picture the detector looks at — never the picture anyone else sees — so it can still find your outline. Does nothing at all in ordinary light.

🖥 System

⚙️ Advanced

Advanced troubleshooting & self-hosted deployments.

TURN relay credentials

A TURN server relays your audio when a firewall blocks a direct peer-to-peer connection. Get a free pair from metered.ca → TURN Server (an app-name subdomain and an API key).

Fallback relay

Used only when no credentials are set above, so peers behind strict firewalls can still connect.

Video routing

Camera and screen-share video can route directly between participants (peer-to-peer) or, for large rooms, through Cloudflare's relay servers, which forward — and can technically see — the video. This never applies to voice, which always stays peer-to-peer.

Network usage

How much data Voxal is moving right now, and what it is carrying. Measured in the main window — this one has no connections of its own — so it only shows numbers while a call is live there.

Jitter buffer

How much incoming audio to buffer before playing it. Higher values smooth out choppy audio on a lossy or relayed connection, at the cost of a little delay. Automatic raises it on its own when a link starts dropping packets.

80 ms

0 ms leaves it to the browser. While Dev mode is on and you are the room host, this value is also pushed to everyone in the room (peers who set their own value keep theirs).

When a room host has dev mode on, an “i” button appears next to each name showing device, audio & network diagnostics. This is off until you accept — nothing is shared otherwise.
